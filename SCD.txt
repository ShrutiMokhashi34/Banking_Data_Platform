===============================================================================
BANKING DATA PLATFORM — SCD STRATEGY
===============================================================================

SCD METADATA COLUMNS FOR TYPE 2 TABLES
--------------------------------------

effective_from     DATE/TIMESTAMP
effective_to       DATE/TIMESTAMP
is_current         BOOLEAN
batch_date         DATE
load_timestamp     TIMESTAMP

IMPORTANT:
- batch_date      = date of the source batch being ingested
- load_timestamp = actual timestamp when Airflow loaded the record
- effective_from = when this version of the record became valid
- effective_to   = when this version stopped being valid
- is_current     = TRUE for the current version
- Do NOT use batch_date as a replacement for effective_from/effective_to.

    currency_symbol

===============================================================================
STANDARD TYPE 2 METADATA
===============================================================================

For all Type 2 tables, use:

    effective_from
    effective_to
    is_current

For all tables loaded through Airflow, use:

    batch_date
    load_timestamp

Recommended default values:

    effective_from = batch_date
    effective_to   = '9999-12-31'
    is_current     = TRUE


===============================================================================
TYPE 2 CHANGE LOGIC
===============================================================================

When a record's tracked attributes have NOT changed:

    Do nothing.

When a record's tracked attributes HAVE changed:

    1. Close the existing record:

        effective_to = new_batch_date - 1 day
        is_current = FALSE

    2. Insert a new version:

        effective_from = new_batch_date
        effective_to = '9999-12-31'
        is_current = TRUE


Example:

CUSTOMER_ID = CUST00005000

Old:

    customer_id       = CUST00005000
    risk_rating       = LOW
    customer_status   = ACTIVE
    effective_from    = 2026-08-01
    effective_to      = 2026-08-03
    is_current        = FALSE

New:

    customer_id       = CUST00005000
    risk_rating       = MEDIUM
    customer_status   = ACTIVE
    effective_from    = 2026-08-04
    effective_to      = 9999-12-31
    is_current        = TRUE


===============================================================================
IMPORTANT
===============================================================================

Do NOT treat these as SCD Type 2 columns:

    batch_date
    load_timestamp

They are INGESTION METADATA.

SCD Type 2 columns are:

    effective_from
    effective_to
    is_current

This distinction is important for your Airflow → Snowflake → Databricks
→ dbt architecture.
