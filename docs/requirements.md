# Functional Requirements

The platform should:

- Ingest daily transaction files
- Ingest customer master data
- Ingest account information
- Load exchange rates
- Load holiday calendar data
- Perform automated data quality checks
- Process data using Medallion Architecture
- Store curated data in Snowflake
- Apply dbt transformations
- Build executive dashboards
- Build operational dashboards

---

# Non-functional Requirements

- Scalable
- Modular
- Automated
- Auditable
- Secure
- Reusable
